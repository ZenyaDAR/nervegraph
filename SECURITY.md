# Security Policy

## Reporting a Vulnerability

If you find a security issue in nervegraph (e.g. path traversal in the scanner, arbitrary file read via `nerve view`'s local server), please **do not open a public issue**. Instead report it privately via GitHub's [private vulnerability reporting](../../security/advisories/new) on this repository.

Include:
- A description of the issue and its impact
- Steps to reproduce
- Affected version

We'll acknowledge reports within a few days and aim to ship a fix before any public disclosure.

## Supported Versions

Pre-1.0 — only the latest published version is supported.
