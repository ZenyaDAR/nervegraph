Keyboard

  • / or Ctrl+K — search
  • f — fit graph to screen
  • g / t — galaxy ↔ tree layout
  • i — issues panel (unresolved refs and cycles)
  • c — cycle through color-by modes
  • Esc — clear selection
  • ? — this card

Mouse

  • click — select a file
  • Shift+click — shortest path from the selected file
  • drag — pin a node where you drop it

Reading the graph

  • ring around a node — entrypoint
  • dashed outline — referenced but missing on disk
  • dashed line — code import; solid — structural inclusion
  • red line — part of a dependency cycle
